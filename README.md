### 🎱 البلياردو — 5 أنواع بمحركات قواعد مرخّصة الإصدار (versioned rulesets)

| النوع | الهيئة/المرجع | أبرز الخصائص |
|---|---|---|
| 8-Ball | **WPA** | كسر قانوني، طاولة مفتوحة، مجموعات ممتلئة/مخططة |
| Blackball | **EPA International v2d** | كسر بالنقاط ≥3، كرة يد، 9 حالات خاصة (جمود/التصاق/تدخل خارجي) |
| **غولڤازور GOLVAZOR** 🇲🇦 | قواعد مغربية أصيلة (v1.0) | 5 أنواع إنهاء، جزاء الضربتين، الانتحار — *أول تقنين رقمي لهذه اللعبة* |
| Snooker | **WPBSA** | تناوب أحمر/لون، ترشيح بالنقر، إعادة الألوان للبقع، الموت المفاجئ |
| Carom الفرنسي | **UMB** | بلا جيوب: الحرة / وسادة واحدة / 3 وسائد |

**عن الغولڤازور** — نسخة مغربية على طاولة وكرات البلاكبول:
- **5 أنواع إنهاء**: ديريكت · ديرنيي ترو (آخر حفرة) · بوند 2–5 (ملامسات وسائد للسوداء) · أنونص (إعلان الحفرة بالنقر عليها) · أنونص + بوند
- **جزاء الضربتين المتتاليتين**: الخطأ يمنح الخصم ضربتين والبيضاء تبقى مكانها؛ سقوط البيضاء = كرة بيد وراء الخط الأبيض حصراً + ضربتان — **ولا جزاء إطلاقاً قبل تحديد مجموعات اللاعبين**
- **الضربة الحرة**: أول ضربة جزاء يجوز فيها لمس/إسقاط ألوان الخصم (لا السوداء)
- **قواعد الكسر**: السوداء وحدها = فوز ساحق · السوداء مع أي كرة = انتحار · لونان مختلفان = حق اختيار اللون بالنقر على كرة في الطاولة
- **الانتحار** (خسارة مباشرة): السوداء مبكراً / مع البيضاء / لمس الخصم عندها / حفرة خاطئة / بوند ناقص

```

│   │   ├── billiards-physics.js   فيزياء مشتركة (240Hz، وسائد كمقاطع، REC للأحداث)
│   │   ├── billiards-rules.js     5 محركات قواعد مستقلة عن الفيزياء والواجهة
│   │   ├── billiards.js           الواجهة (Canvas + HUD + أونلاين)
│   │   ├── chess.js · dama.js · ronda.js · rami.js · parchisi.js …
│   │   └── catalog.js             كتالوج الألعاب وبطاقات القواعد
│   ├── i18n/translations.js   4 لغات: العربية · الفرنسية · الإنجليزية · الدارجة المغربية
│   └── rules/                 نصوص القواعد الكاملة داخل التطبيق
└── tests/                     أطقم اختبار Node لكل محرك (اختبار كل بند مقابل نص القاعدة)
```

### المبادئ الهندسية

1. **فصل الفيزياء عن القواعد عن الواجهة**: محرك الفيزياء يُنتج سجل أحداث (REC)، ومحرك القواعد يحكم على قانونيتها، والواجهة ترسم فقط — كل محرك يعمل في Node (للاختبار) وفي المتصفح بنفس الملف.
2. **محركات قواعد مُصدَّرة بإصدارات** (versioned rulesets): كل نوع يحمل `ruleset_id/version/authority` لأن الهيئات تنشر تحديثات.
3. **أونلاين حتمي (deterministic lockstep)**: تُبثّ أوصاف الضربات (زاوية/قوة/دوران) عبر SSE وتُعاد محاكاتها بعدد خطوات مطابق عند كل طرف — مع إعادة بناء كاملة للعائدين من انقطاع (replay).
4. **إثبات العدالة**: ألعاب الحظ تستخدم commit-reveal — يُنشر hash البذرة قبل الجولة وتُكشف بعدها.
5. **بلا تبعيات إنتاج**: الخادم Node خام والواجهة Vanilla JS — لا build ولا bundler.
